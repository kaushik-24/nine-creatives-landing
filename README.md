# Nine Creatives — Digital Strategy & Web Growth Engine

Nine Creatives is a digital strategy and growth studio engineering high-converting web platforms and client acquisition funnels for service businesses across Australia and the UK.

## 🚀 Key Features

- **Single-Page Landing Experience**: Integrated smooth anchor navigation, real-time active scroll-spy, and high-conversion strategy call booking funnels.
- **Dedicated Work & Proof of Impact**: Comprehensive case study showcase (`/work`) featuring real client platforms, macOS-style browser mockups, bottleneck-to-solution breakdowns, and verified ROI metrics.
- **Curated Color & Visual Design**:
  - `Bone White` (`#F9F6EE`)
  - `Midnight Ink` (`#0f1330`)
  - `Growth Emerald` (`#23c17c`)
  - `Strategic Sapphire` (`#4f8fe6`)
- **Interactive Capabilities**:
  - Custom GLSL animated shader hero
  - 3D interactive portfolio carousel
  - Client testimonials & proof metrics
  - Fully responsive mobile drawer navigation

## 🛠 Tech Stack

- **Framework**: Next.js 15 (App Router, React 19)
- **Styling**: Tailwind CSS v4, Vanilla CSS Design System Tokens
- **Typography**: Cabinet Grotesk (Display) & Switzer (Sans)
- **Icons**: Lucide Icons
- **Animation & Visuals**: WebGL Shaders, CSS 3D Transforms

## 📦 Getting Started

### Prerequisites

- Node.js (v18.17+ or v20+)
- npm / pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/kaushik-24/nine-creatives-landing.git

# Navigate into the project
cd nine-creatives-landing

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

### Production Build

```bash
npm run build
npm start
```
